# 智域·园区综合资源协同调度系统（简历定稿）

**2025.09 – 2026.01**　　　　**智域·园区综合资源协同调度系统**　　　　**后端开发**

**项目简介：**  
面向园区后勤 **物资申领、档口下单与库存管理** 场景，针对人工台账响应慢、库存数据分散在多表、高峰期列表查询压力大等痛点，开发 O2O 资源治理后台与小程序用户端。实现资源分类建模、订单全流程跟踪、权限管控与自动结算相关能力，通过缓存与并发控制保障下单链路稳定，支撑园区日常物资流转数字化管理。

**技术栈：**

- **业务后端：** Spring Boot、Spring MVC、MyBatis、MySQL  
- **安全与会话：** JWT、拦截器、ThreadLocal  
- **缓存与并发：** Redis（缓存、分布式 ID）、MyBatis 乐观锁  
- **工程化：** PageQueryDTO、MyBatis 动态 SQL、VO 返回、PageHelper、Spring AOP  

**个人职责：**

- **统一认证与用户上下文：** 针对多接口需重复校验登录态、业务层手动传递用户信息易遗漏的问题，使用 **JWT + Spring MVC 拦截器** 完成鉴权，并通过 **ThreadLocal** 在请求链路内传递当前用户，保证身份识别一致、线程间数据隔离。  

- **热点数据缓存：** 针对档口分类、资源信息等读多写少接口频繁访问 MySQL 的问题，使用 **Redis** 手动维护缓存，结合 **空对象缓存** 与 **互斥锁** 缓解缓存穿透、击穿，降低数据库访问压力，提升列表类接口的响应稳定性。  

- **下单与库存一致性：** 针对并发下单可能导致库存超扣的问题，基于 **Redis 生成全局唯一订单 ID**，并在扣减库存时使用 **MyBatis 乐观锁（version 字段）**，在冲突时触发重试/失败提示，保证库存扣减逻辑可控、避免超卖。  

- **公共字段自动填充：** 针对各业务表重复编写创建时间、更新时间、操作人等字段、易漏填的问题，使用 **Spring AOP + 自定义注解 + 反射** 在持久化前自动注入公共字段，减少样板代码，提升后续表结构扩展时的维护效率。  

- **分页条件查询与多表展示：** 针对管理端列表需按名称、分类、状态等筛选且带分页的问题，前端通过 **GET 查询参数** 提交，后端用 **PageQueryDTO** 接收（非 RequestBody）；在 **MyBatis XML** 中用动态 SQL 拼接条件，查询侧 **LEFT JOIN** 关联分类等表并以 **VO** 返回（如菜品 + 分类名），配合 **PageHelper** 分页，避免 Controller 堆叠零散入参。
